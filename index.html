01 — INTRODUCTION

What is Python?

Python is a high-level, general-purpose programming language known for its simple and readable syntax. It is used in web development, automation, data analysis, artificial intelligence, and many other areas of technology.

Python is a good language for beginners because its syntax is easy to read and understand.

Py

Why learn Python?

  • Easy-to-read syntax
  • Beginner friendly
  • Large community
  • Useful in many IT fields

02 — BASICS

Python Fundamentals

Here are some basic concepts to help you get started.

01

Variables

Variables store information that can be used later in a program.

name = "Timothy"
age = 20

print(name)
print(age)
02

If / Else

Conditional statements allow a program to make decisions.

age = 18

if age >= 18:
    print("Adult")
else:
    print("Minor")
03

Loops

Loops repeat a block of code several times.

for number in range(1, 6):
    print(number)
04

Functions

Functions organize reusable instructions in your program.

def greet(name):
    print("Hello", name)

greet("Timothy")

03 — EXAMPLES

Simple Python Programs

Try to understand each example before running it.

01

Simple Calculator

This program asks for two numbers and calculates their sum. You can modify it to perform other mathematical operations. 

num1 = float(input("Enter first number: "))
num2 = float(input("Enter second number: "))

sum = num1 + num2

print("The answer is:", sum)
02

Check Even or Odd

The modulo operator (%) can be used to determine whether a number is even or odd. 

number = int(input("Enter a number: "))

if number % 2 == 0:
    print("The number is even.")
else:
    print("The number is odd.")
